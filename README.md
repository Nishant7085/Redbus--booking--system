# RedBus Booking System in C++

## About the Project

This is a simple bus ticket booking system developed using C++.

## Features

* Display available buses
* Show bus details
* Book bus tickets
* Display available and booked seats
* Prevent booking an already-booked seat

## Concepts Used

* Classes and Objects
* Constructors
* Arrays
* Member Functions
* Conditional Statements
* While Loops

## How to Run

1. Download or clone this repository.
2. Open `main.cpp` in a C++ compiler.
3. Compile and run the program.
